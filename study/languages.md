| Language | What it is | Your use |
|---|---|---|
| **TypeScript** | JavaScript + types. Catches bugs before runtime. | FytlY RN, portfolio, Glow Comments-ish tooling |
| **Swift** | Apple’s main language for iOS/macOS. | Metal / native graphics path |
| **Python** | General scripting + ML/data ecosystem. | Automation, study, one-off tools |

**Don’t claim:** “expert in all three equally.” Claim a **primary** (TS) and **competent when needed** (Swift/Python).
