# Cursor skills & Antigravity skills

Portfolio claim: you don’t just “use ChatGPT” — you encode **repeatable agent workflows** as skills.

---

## Say this (60 seconds)

> “I work with AI coding agents daily — **Cursor** and **Antigravity**. A **skill** is a markdown playbook the agent loads for a job: rules, file layout, commands, do/don’t. Instead of re-explaining my stack every chat, I point the agent at a skill so it follows the same architecture as FytlY or my portfolio. That’s how I keep speed without letting the model invent a new pattern every time.”

---

## Plain English

### Cursor skills
- Live under things like `.cursor/skills` / user skills folders.
- Example jobs: “commit with our style,” “review PR,” “follow RN saga rules.”
- Your FytlY rules (Redux-Saga, `respWidth`, no `@/` aliases) are the same idea: **constrain the agent**.

### Antigravity skills
- Google’s agentic IDE / agent product you use alongside Cursor.
- Same concept: **skills / workflows / AGENTS.md** so the agent knows project law.
- Your Everything folder already bridges tools via root **`AGENTS.md`** (constitution for every agent).

### Why employers care
- Shows you can **operationalize** AI (process), not only paste prompts.
- Shows **governance**: secrets, LOC limits, verify with `npm run build`.
