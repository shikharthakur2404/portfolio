> Bridges to root constitution: @../AGENTS.md

## Project Facts
- **Purpose**: Interactive personal portfolio showcasing FytlY, Emergency Mesh Nürnberg, AI Research paper, Glow Comments, and Visual Computing triad.
- **Stack**: React 19, TypeScript, Tailwind CSS v4, Vite 8, Lucide React.
- **Commands**:
  - Dev: `npm run dev`
  - Build: `npm run build` (`tsc -b && vite build`)
  - Lint: `npm run lint` (`oxlint`)
- **Conventions**:
  - Modular component architecture under `src/components/`.
  - All components strictly < 200 LOC.
  - Dual-Theme support: Dark mode (primary HUD) & Light mode (clean, high-contrast).
